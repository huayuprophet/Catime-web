# Catime-web

一款简洁实用的网页版番茄计时工具。

## 📋 简介

Catime-web 是一款基于 Vue 3 和 Element Plus 开发的网页版番茄计时器应用。它不仅支持基础的倒计时和正计时功能，还实现了复杂的番茄钟工作法，帮助用户提高工作效率。项目采用现代化的前端技术栈，界面简洁直观，功能丰富实用。

> ⚠️ 注意：项目目前仍在积极开发中，部分高级功能仍在完善中。

## ✨ 主要功能

### 🕐 计时功能
- **倒计时** - 支持多种时间格式输入（如：2.6.50 表示 2小时6分钟50秒，2.20 表示 2分钟20秒，120 表示 120分钟）
- **正计时** - 从零开始计时，适合记录已完成的时间
- **番茄钟** - 支持自定义专注时间和休息时间，可设置重复次数和大课间休息

### 🔔 任务自动化
- **任务系统** - 支持在计时结束时执行多种任务类型
- **预设任务** - 包含通知、铃声播放、打开URL等多种预设任务
- **自定义任务** - 支持自定义JavaScript函数执行

### 🎛️ 控制与管理
- **群控功能** - 支持批量控制所有计时器（全部暂停、继续、停止、重置、删除）
- **状态管理** - 完整的状态管理（运行中、暂停、停止、结束）
- **计时器管理** - 支持创建、编辑、删除多个计时器

### 🎨 用户体验
- **可视化进度条** - 直观显示计时进度
- **实时时间显示** - 顶部实时显示当前时间
- **响应式设计** - 适配不同屏幕尺寸
- **大字显示模式** - 适合远距离查看的上墙功能

## 🛠️ 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Element Plus** - 基于 Vue 3 的 UI 组件库
- **Pinia** - Vue 官方推荐的状态管理库
- **Vite** - 现代化前端构建工具
- **Bootstrap** - CSS 框架

## 🚀 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm 或 yarn

### 安装步骤
```bash
# 克隆项目
git clone https://github.com/huayuprophet/Catime-web.git

# 进入项目目录
cd Catime-web

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 构建生产版本
```bash
# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 📖 使用说明

### 创建计时器
1. 在左侧边栏的"快速创建"面板中选择计时类型（倒计时或番茄钟）
2. 输入时间设置并点击"创建"

### 时间格式说明
- **倒计时格式**：
  - `[时].[分].[秒]` - 如 `2.6.50` 表示 2小时6分钟50秒
  - `[分].[秒]` - 如 `2.20` 表示 2分钟20秒
  - `[分]` - 如 `120` 表示 120分钟
  - 也可以使用 `.40` 表示 40秒，`1..48` 表示 1小时48秒

- **番茄钟设置**：
  - 专注时间：每次专注的时间长度
  - 休息时间：每次休息的时间长度
  - 重复次数：专注-休息循环的次数
  - 大课间：每完成一轮循环后的长休息时间

### 任务配置
在计时器结束时，可以配置执行以下任务：
- 重启定时器
- 设置定时器
- 跳转到结束
- 发送通知（普通通知或系统通知）
- 播放声音（支持音量和持续时间设置）
- 打开URL
- 移除定时器
- 自定义函数执行
